# 📰 News App

A simple News App built using HTML, CSS, and JavaScript.

This app uses the NewsData.io API to show the latest news. Users can search news, browse different categories, and save their favourite news using LocalStorage.

## 🚀 Features

- 🔍 Search News
- 📰 Category-wise News
- ❤️ Add and Remove Favourite News
- 💾 Favourite News saved in LocalStorage
- 🏠 Home Button
- 📅 News Published Date
- 📰 News Source
- 🖼️ Default Image if image is not available
- ⏳ Loading Spinner
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- NewsData.io API
